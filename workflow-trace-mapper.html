How to use this in the paper

  • Use trace events as observed messages and actions in the organizational graph.
  • Use triage/decision/resolution latency as proxies for τ.
  • Use quality, rework, or SLA success as proxies for I(X;A).
  • Use handoffs and event count as proxies for coordination cost.
  • Compare human-heavy and agent-assisted traces after controlling for case complexity.
This does not directly estimate Shannon mutual information. It creates an observable measurement path toward the theory.
