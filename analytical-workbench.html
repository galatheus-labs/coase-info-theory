A boundary can be lossy and still be worth drawing.

This workbench evaluates explicit analytical assumptions. It contains no fitted organizational parameters and is not empirical evidence. The scenario companion uses a different heuristic model.

1. The economic switching threshold

Scalar Gaussian estimation; quadratic loss; memoryless samples; optimal asymptotic one-way coding. Coordination savings are held fixed as capacity varies. All loss and cost quantities use common objective units per decision.

Δ(κ) = Δ(0) × 2^(−2κ); J_split − J_coalesced = Δ(κ) − H

A positive deficit is not a prohibition on splitting. Capacity-dependent interface cost or coding delay makes H a function of κ and invalidates this fixed-H closed form. A one-shot handoff need not achieve the asymptotic bound.

2. How many units?

Balanced groups, quadratic within-unit cost, and a tree-like graph with constant cost B on each of m−1 interfaces. Decision loss is held fixed. Internal burden A is not cross-boundary decision dependence.

Θ(m) = A/m + B(m−1); continuous optimum = clip(√(A/B), 1, N)

Conditional comparative static: Δlog m* = ½(Δlog A − Δlog B), only in the interior continuous model. Agents can favor integration when internal costs fall proportionally more than interface costs.
